# Toby

Toby is Tavin's personal team of bots, built on the open-source Gratis community edition (MIT licence; see LICENSE, which must stay in place).

## What's different from Gratis
- App name, data folder and app ID: `edition.json` (Toby, `%APPDATA%\Toby`, com.blueonehundred.toby)
- Installer name, shortcut and Windows icon: `electron-builder.cjs`, `assets/toby-icon.png` (signAndEditExecutable is on so the .exe carries the Toby name and icon; there is no code-signing certificate, so nothing is signed)
- User-facing wording: "Gratis" replaced with "Toby" in `src/` (one-for-one, no logic changes)
- Windows build: `.github/workflows/toby-windows.yml` (Actions tab, "Build Toby for Windows", Run workflow)
- **Fixed bot order** (Toby-only): `src/sidebar-items.mjs` (`TEAM_ORDER`) keeps bots in team order instead of by recent activity; group chats come after the bots. Pinned bots get a "Team lead" label when Toby is the only one pinned (`src/renderer.mjs`, `src/bot-tile.css`). Add new team bots to `TEAM_ORDER`.
- **Custom connections** (Toby-only): Settings → Connections → Custom connections. Any MCP server (e.g. treg, Apify) with name, https address, token (stored encrypted in connections.secure, never shown) and "Ask me before each use". Given to bots with Connected apps on (`src/connections.mjs`, `src/agent-tools.mjs`, `src/claude-backend.mjs`, `src/workspace-ui.mjs`, `src/index.html`). Tests: `test/custom-connections.test.mjs`.
- **Image tool** (Toby-only): `view_image` for bots with Web on: fetches a public https image (PNG, JPEG, WebP, GIF, up to 4.5 MB, private addresses blocked) so the bot can see it; optional saveAs into Files (`src/web-tools.mjs` fetchImage, `WorkspaceFiles.writeBytes`).
- **Real local time** (Toby-only): `localTimeLine()` in `src/claude-backend.mjs` adds the computer's local date and time to each tool-enabled bot's instructions every turn, so run logs and briefs use the real time.
- **Shared team folder** (Toby-only feature): `src/team-folder.mjs`, wired in `src/main.cjs` and `src/agent-tools.mjs`. Every bot with Files on gets `list_team_files`, `read_team_file`, `write_team_file`, `append_team_file`, `copy_to_team` and `copy_from_team`, all limited to one folder: `Desktop\Toby\Income` (or `TOBY_TEAM_FOLDER`; `<data>\team-folder` when a test data folder is set). Same safety rules as private Files (no `..`, hidden paths or symlinks; one write at a time), 500 MB / 5,000 files. Tests: `test/team-folder.test.mjs`. When merging Gratis updates, keep the `teamFolder` lines in those three files.

- **Build 6, research-friendly runs** (Toby-only, 13 Nov 2026): `src/run-limits.mjs` counts tool failures **in a row** (a success resets the count) and upgrades the old Gratis defaults (10 min, 100 calls, 5 failures) to 30 min, 200 calls, 8 failures in a row. `read_webpage` and `view_image` return blocked or missing pages as a normal result (`opened:false`) instead of a tool error; the page reader identifies as a desktop browser; `search_web` asks Bing for US-English results. `MAX_MCP_OUTPUT_TOKENS=60000` in `src/claude-backend.mjs` so large paid-data results stay readable. Tests: `test/toby-build6.test.mjs`.
- **make_pdf** (Toby-only): bots with Files get `make_pdf` (team-folder HTML to team-folder PDF) using Chromium's printer in a hidden window with scripts off and network blocked (`src/pdf-maker.cjs`, wired in `src/main.cjs`). Books use CSS `@page` rules (size, margins, margin boxes for page numbers).
- **make_book** (Toby-only): bots with Files get `make_book`, which assembles Markdown parts from the team folder into one designed book (cover with real-text title over an optional image, contents, chapter openers, styled boxes for The short version / Try tonight / Remember / Safety note / Red flag / Tip / From <name>'s <place>, tables, [S12] tags) and saves HTML and PDF (`src/book-builder.mjs`).
- **Build 8 book design** (Toby-only): `make_book` makes a full-page cover (badge, tagline, author optional), drops hand-written Contents sections, designed chapter openers (optional `chapterImagesDir/chNN.png` art), visual blocks from labelled blockquotes (Stat tiles, Steps cards, Checklist tick boxes, Timeline, Before/After panels, Quote, Key idea), keeps lead-in lines with short lists, splits long tables with repeated headers, and lays out Sources as a list. Large images are shrunk with Electron's nativeImage.
- **save_image_to_team** (Toby-only): bots with Files download a public PNG/JPEG/WebP (up to 30 MB) straight into the team folder. `view_image` accepts `image/jpg` and shrinks images over 4.5 MB instead of refusing them.
- **Team order** updated for the 7-step creator process: Toby, Daily Planner, Product Scout, Ebook Builder, Creator Partnerships, Outreach Writer, Partner Manager, Creative Studio, Income Coach, Maintenance, Lead Researcher.
- **Build 14, companion apps** (Toby-only, 15 Nov 2026): bots with Files get `make_app` (`src/app-builder.mjs`): it turns a book or creator edition's Markdown parts in the team folder into one self-contained companion app (`<bookDir>/app/index.html`) and an `app-check.md` note. The design is the template in the team folder (`templates/app/template.html`), so it can change without a new build. Bots with Files and Connected apps also get `publish_app` (`src/app-publisher.mjs`) once a custom connection named **`app_publisher`** exists: address `https://github.com/<owner>/<repo>` (the repository Vercel serves; add `?site=https://...` for another web address), token a GitHub fine-grained token with Contents read and write on that one repository. That connection is a publishing key only: it is never offered to bots as a tool server. Each app is uploaded to `<name>-<8 random characters>/index.html`, the link is saved in `app/app-link.md`, and an app whose check has not passed is refused. Team order adds App Builder, Store Manager and Marketing Kit. Tests: `test/toby-app.test.mjs`.
- **Build 28, Motion Studio tools** (Toby-only, 17 Nov 2026): bots with Files get `make_reel` (`src/reel-builder.mjs`, `src/reel-maker.mjs`: a port of Jane's approved reel code; the reel is one HTML page drawn frame by frame offscreen with `renderFrames` in `src/pdf-maker.cjs` and encoded by the bundled ffmpeg, `ffmpeg-static`, unpacked from the asar), `make_video_clip` (`src/video-clip.mjs`: fal queue API with the fal connection's key, Kling 2.5 Turbo Pro; a $1.50-a-reel cap kept in `<data>/fal-spend.json`, over it Toby's approval prompt asks Tavin; every clip logged in `samples/credits-<month>.md`) and `make_sound` (`src/sound-maker.mjs`: ElevenLabs sound effects and music with the key in a custom connection named `elevenlabs`, address `https://api.elevenlabs.io`, never treated as an MCP server; takes measured and ranked by `rankTakes` in `src/media.mjs`). Tests: `test/toby-motion.test.mjs`; `test/motion-desktop.mjs` makes a reel inside the packaged app on the Windows build.
- **Build 31, longer bot instructions** (Toby-only, 18 Nov 2026): a bot's instructions may be up to 32,000 characters (Gratis: 16,000) in `src/chat-service.mjs` (`INSTRUCTIONS_MAX`), `src/bot-template.mjs` and the bot settings box in `src/index.html`. Other text limits (memory, user prompt template, schedule prompts, messages between bots) stay at 16,000. Tests: `test/toby-limits.test.mjs`.
- **Build 32, no needless red errors** (Toby-only, 18 Nov 2026): `src/soft-results.mjs`. When a reading tool (read_file, read_team_file, zoom_team_image, view_image, copy_from_team, copy_to_team) is given a file that does not exist yet, or read_webpage/view_image gets an HTTP error page, or a PDF's text cannot be read, the bot gets a normal answer (`found:false` / `opened:false` / `read:false` with a note) and the activity row shows as complete, not as a red error; it no longer counts toward the 8-failures-in-a-row run limit. Real faults stay errors. Tests: `test/toby-soft-results.test.mjs`.
- **Build 33, plan week lines** (Toby-only, 18 Nov 2026): `src/app-builder.mjs` takes the Plan tab's week lines only from a timeline whose items all start "Week N:". Before, the last timeline in the book won, so every sourdough app showed the loaf-cooling steps ("First hours: Leave it uncovered on a rack...") under "Week 1". Test in `test/toby-app.test.mjs`.
- **Build 34, big tool answers** (Toby-only, 18 Nov 2026): `src/tool-results.mjs`. When a tool answer is too big for the chat, the Claude Agent SDK saves it under `~/.claude/projects/<workspace>/<session>/tool-results/` and tells the bot to read it; read_file refused anything outside the bot workspace (red "Use a path inside the bot workspace."), so bots missed the end of big files such as the month's decisions file. read_file now reads exactly those files, read-only, only for the conversation that made them, in 40,000-character parts (`part`). Test: `test/toby-tool-results.test.mjs`.
- **Build 35, fixes from Erica's run** (Toby-only, 18 Nov 2026): (1) `src/claude-backend.mjs` `toolResultActivity`: a bot asking for a tool it does not have ("No such tool available: Bash", "This tool is not enabled for this bot") is shown as `skipped`, not a red error, and does not count towards the repeated-failures stop. (2) read_file `find`: search a saved tool result for a word, matching lines with line numbers (`src/tool-results.mjs` `findInToolResult`), so bots never need Bash or grep. (3) Books: the paw icon (left from the puppy book) is gone; "From" boxes use a quote mark and "Did you know?" cards a sparkle (`src/book-style.mjs`, `src/book-builder.mjs`). (4) Carousels: the flag slide always sits on the deep colour, so the card layout's Safety note passes contrast (was 4.4:1 on terracotta). (5) make_carousel moves slides a shorter remake no longer has into `<folder>/_old-<time>/`. Test: `test/toby-build35.test.mjs`.
- **Build 36, package runs** (Toby-only, 18 Nov 2026): one request runs a creator's whole package. `src/pipeline.mjs` (`Pipelines`, wired in `src/main.cjs`, ticking every 5 seconds like schedules) messages each bot in turn through `service._deliver` (labelled "Package @handle: <bot>"), waits for its reply, then checks the step's gates: files written in this run, the bot's own check files ("Result: PASSED"), the automatic package check and, for the app, a phone-size check. A failed step gets one fix run with the reasons (Marketing Kit's goes to Art Director first, Visual Check's to Marketing Kit first); a second failure stops the run. The last step writes `pipeline/<handle>/review.html` for Tavin. Steps live in `pipeline/steps.json` in the team folder (written from `DEFAULT_STEPS` the first time, so they can change without a build); runs are saved in `<data>/pipelines.json`; status in `pipeline/status.md` and `pipeline/<handle>/status.md`; a run line per step in `board/runs-<date>.md`. Starting a run appends one decided line for all eight bots. Tools: `check_package` and `package_status` for bots with Files; `start_package`, `approve_package` and `stop_package` for the bot named Toby only. `src/package-check.mjs` holds Claude's 18 Nov manual checks as rules (From-box quotes found in the voice file, her family and tagged brands kept out, UK spelling in US books, 2 carousels with disclosed captions and no "comment for the recipe", the email's app link, carousel line, quotes of 8 words or fewer, chapters that hold her boxes, no "grew from", no postal address placeholder, the breakdown arithmetic). `src/app-phone-check.mjs` opens the app at 390 x 844 in `renderPage`, clicks "Skip for now", every tab and Chapter 5, and reports sideways scrolling, broken pictures and a "First hours" Plan tab. `src/carousel-builder.mjs`: panel-layout words always sit on the deep colour (a long cover title had pushed the kicker onto the photo). Tests: `test/toby-build36.test.mjs` (synthetic creator only).
- **Build 38, the creator progress log** (Toby-only, 19 Nov 2026): `src/creator-log.mjs` (`CreatorLog`, owned by `Pipelines` as `pipelines.log`) keeps `creators/creators-log.csv` (one row per creator, 15 stages from Found to Live on Whop) and rebuilds `creators/creators-log.html` after every change. Only code writes it: once a minute it adds new creators from the "## Ranked list" table of Creator Partnerships' `creators/<date>.md` files (stage Found, existing rows never touched); a package run sets Picked on start, moves the row on each time a step passes (voice 3, look 4, edition 5, app 6 with the app link, carousels 7, visual 8, email or DM 9), notes a stopped run, and `approve_package` sets Approved. Toby-only tool `set_creator_stage` records Sent, Replied, Yes, No, Store + launch kit and Live on Whop when Tavin says so. Log errors never break a run. Tests: `test/toby-build38.test.mjs` (made-up creators only). (No build 37 code: release 37 carries build 36.)
- **Build 39, no false alarms** (Toby-only, 19 Nov 2026): `src/renderer.mjs` shows a tool error (red box) only when the reply itself failed or was stopped; a tool error the bot got past is not shown (still in X-ray). `src/schedules.mjs`: a scheduled run cut short by Toby closing or by a run limit (`cutShort`) is recorded as "interrupted", keeps its schedule on and appends a run line to `board/runs-<date>.md` (Schedules gets `teamFolder`); a run the user stopped still pauses its schedule. `baseName` in `src/pipeline.mjs` (and `runPackageCheck`) accepts "ebooks/<slug>" for the base book. Tests: `test/toby-build39.test.mjs`.
- **Build 40, never an empty morning** (Toby-only, 19 Nov 2026): `src/schedules.mjs`: a scheduled run that hits a run limit (`hitLimit`) gets one fresh "save your work" turn (`WRAP_UP`, run kind `wrapup`, never a second); closing Toby gets none. `src/pipeline.mjs` `watchCreators`: on weekdays 08:15 to 17:00, if `creators/<date>.md` has no "Status: done" and Creator Partnerships is idle (and has had a run today, or it is past 10:00), the app sends one second-try message (`secondTryMessage`, ready-book creators first), writes `pipeline/second-try-<date>.md` and a run line. `src/creator-log.mjs` `details`: a package started for a creator outside a ranked list fills her log row from the newest creators file (near-miss tables too). Book covers: titles over 20 characters move the sources seal up onto the photo (`.seal.high`). Tests: `test/toby-build40.test.mjs`.
- **Build 41, real times** (Toby-only, 19 Nov 2026): bots only got the time when a turn started and guessed later times (15 to 40 minutes ahead, partly to keep the board "in order"). Now `append_team_file` writes the real time over the start of every run line in `board/runs-<date>.md` (`stampRunLines` in `src/claude-backend.mjs`; `write_team_file` never restamps), `write_team_file`/`append_team_file` answers carry `time`, `list_team_files` ends with the real time, and the time line in the instructions says to use those and never guess. Tests in `test/toby-build40.test.mjs`.
- **Build 42, book types** (Toby-only, 19 Nov 2026): `src/book-types.mjs`. A base book's `plan.md` may say `Type: care`, `recipe`, `project` or `routine` (an edition or sample reads the base book's). `make_book` then sets `> Recipe:` and `> Project:` cards, `> This week:` grids and "What went wrong" / "Looks like" tables, and checks the book against its type (no "Say this, not that" in recipe or project books, "Try tonight" only in care books, each type's own card present; a type marked "(please confirm)" never passes). `check_edition` keeps every card line instead of counting it as box text. `make_app` gives the general template the type's tabs (care: Plan, Log; recipe: Recipes with servings you can change, Timer; project: Projects, Progress; routine: This week, Streak). A book with no Type line gets byte-for-byte the same book, app data and edition check as build 41. Tests: `test/toby-build42.test.mjs` (made-up books in `test/fixtures/typed-books.mjs`).

## Pulling in Gratis updates
```
git remote add upstream https://github.com/earlyaidopters/gratis-community.git   # once
git fetch upstream
git merge upstream/main
# re-run: grep -rn "\bGratis\b" src   and replace any new user-facing "Gratis" with "Toby"
```
Then run the Windows build again. Keep the previous installer for rollback.
