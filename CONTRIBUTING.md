# Contributing to the community edition

Use this public repository for community features, examples and exercises. Follow `AGENTS.md` and `docs/BUILDING_COMMUNITY.md`.

Make changes in `src/`, keep examples synthetic, run `npm run check` and the affected desktop checks, and push only to the community `origin` remote. A shared fix intended for the public core needs a separate, reviewed and sanitized change in that checkout.

Do not include account credentials, member chats or production screenshots in commits or issues. The inherited core source remains MIT-licensed. User workspaces and signing credentials must remain outside this public repository.
