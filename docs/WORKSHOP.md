# Workshop: from one answer to a dependable routine

Use a disposable topic and synthetic material until you understand the flow.

## Exercise 1: define a useful finish line

Ask the guide to help turn a broad goal into one small outcome. Write down the expected output, evidence required, and what would make it wrong. Keep a first run short enough to review manually.

**Check:** You can say why the result is useful and how to verify it.

## Exercise 2: choose the right teammate

Create a group with a guide, builder and reviewer. Send a greeting, then a concrete request. Ask the reviewer to check one part independently. Compare that with `@everyone`, which explicitly asks all participants.

**Check:** The coordinator stays concise and only useful specialists contribute. Distinct checks should produce distinct findings.

## Exercise 3: make memory visible

Tell the bot a real, non-sensitive preference you are comfortable saving. Open Memory, inspect its scope and source, then edit or remove it. Repeat a related task to see what context is reused.

**Check:** No inferred fact is silently treated as something you explicitly said. A remembered preference does not authorize an external action.

## Exercise 4: test a recurring check

Create a schedule that summarizes information in this chat. Use Run now, review the result, then pause and edit the schedule. Verify its timezone and next run.

**Check:** The result appears once, in the right chat. You know the app must remain running and the Mac awake.

## Exercise 5: add one connection

Only after the basic workflow is useful, connect one app you own. Start with read-only work where possible. Inspect requested permissions and verify the response against the source app.

**Check:** The workflow fails clearly when disconnected and does not claim success without an actual result.

## Exercise 6: improve the routine

Record one failure and one change that would prevent it. A smaller prompt, a clearer scope, a better source or a deliberate human checkpoint often helps more than adding another bot.
