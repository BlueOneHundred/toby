Same Gratis app, now packaged for Apple silicon Mac, Intel Mac, Windows x64 and Ubuntu x64. Includes the shared phone computer controls and profile settings.

Download the installer matching your computer. These are unsigned community preview builds, distributed from the private repository. Signing and notarization are not configured yet. See `docs/DOWNLOADS.md` for installation, verification, platform requirements and feature limits.

Existing Gratis data is preserved when updating. Provider accounts, phone pairing, Composio and cloud computers are configured by each user; downloads contain no accounts or chat data.
