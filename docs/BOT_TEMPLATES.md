# Share a bot template

Right-click a bot and choose **Export bot template**. On another Gratis installation, open Settings → **Import bot template**. Review the full system instructions and user prompt before importing.

A template contains name, avatar, instructions, model preferences and required capability names only. It excludes IDs, all memory scopes, transcripts, files, sessions, schedules, credentials and phone pairing. Credential-shaped content in instructions is rejected; this is a safety check, not a guarantee that arbitrary prose contains no personal information. Review your own instructions before distributing them.

An imported bot receives a new identity. All capabilities and personal-profile memory access start disabled. Enable only the capabilities you want and bind your own accounts. The checksum detects accidental modification; it does not authenticate an author. Templates are independent copies, not live team sharing or centrally revocable documents.
